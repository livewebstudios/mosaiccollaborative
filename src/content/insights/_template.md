This file exists to hold the shape of a post and to keep the collection valid. It is
marked `draft: true`, so it never reaches the build. Copy it, rename it, write the
real thing, and set `draft: false`.

## Headings work

Body copy sits at a 62 character measure. Every element below is styled, so a writer
can use ordinary markdown without thinking about the design.

- Lists carry the standard spacing
- A second item, to show the rhythm

> Pull quotes render in Fraunces italic with an accent rule down the left edge, and
> the accent comes from the `heroAccent` field in the frontmatter.

### Smaller headings

Links are [underlined with an offset](/how-we-work/) so they read clearly in running
text. Images get the asymmetric tile radius automatically.

`category` must be one of: Leadership, Culture, Change, AI at work, or
Podcasts & appearances. `heroAccent` must be navy, slate, gold, or burgundy.
